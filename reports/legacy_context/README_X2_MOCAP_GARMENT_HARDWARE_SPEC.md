# X2 动捕服硬件技术参数

- 文档版本：v0.1
- 更新日期：2026-08-31
- 文档性质：工程实测与现有协议核对稿，非硬件厂商规格书
- 适用对象：当前上衣 6 IMU + 裤子 5 IMU 的 SmartWear V2 动捕服

## 1. 文档范围

本文只描述动捕服本体、IMU 传感器、无线通信和原始数据帧。

文中的采样频率属于工程测试结果；姿态精度、续航、重量、防护等级等没有可靠
依据的项目统一列为待确认，不使用推测值。

## 2. 核心参数

| 项目 | 当前参数 | 备注 |
| --- | --- | --- |
| 产品形态 | 分体式上衣 + 裤子 | 两件衣服分别作为 BLE 设备连接 |
| IMU 型号 | BNO085 | 九轴惯性传感器 |
| 上衣有效 IMU | 6 个 | 一帧包含 6 个有效测量槽位 |
| 裤子有效 IMU | 5 个 | 协议保留 6 个槽位，使用其中 5 个 |
| 总有效测量点 | 11 个 | 6 + 5 |
| 直接测量关节数 | 0 | 衣服不直接测量机械关节角度 |
| 单 IMU 当前输出 | 三轴加速度 + 姿态四元数 | 共 7 个数值 |
| 全套有效输出维度 | 77 | 11 IMU x 7 个数值 |
| 无线方式 | Bluetooth Low Energy | 上衣、裤子双设备连接 |
| 数据发送方式 | BLE GATT Notify | 两件衣服分别发送通知帧 |
| Notify UUID | `adaf0101-c332-42a8-93bd-25e905756cb8` | 当前 V2 数据特征 |
| 单设备帧长度 | 137 字节 | SmartWear V2 帧 |
| IMU 时间戳分辨率 | 100 us | 每颗 IMU 独立采样时间 |
| 原始帧频率 | 约 50-67 Hz/件 | 不同固件和连接条件下的工程实测范围，非保证值 |
| 手指独立采集 | 不支持 | 当前衣服没有手指传感器 |

## 3. “关节采样数”的正确表述

这套动捕服没有安装关节编码器，因此不能写成“采样 11 个关节”。准确表述是：

```text
11 个身体 IMU 测量点
= 上衣 6 个 + 裤子 5 个
```

每个测量点提供该身体部位的惯性与方向信息，人体关节角属于后续根据多个 IMU
观测推算的结果，不是动捕服硬件直接测得的数据。

## 4. BNO085 传感器通道

BNO085 硬件包含：

- 三轴加速度计；
- 三轴陀螺仪；
- 三轴磁力计；
- 芯片内部姿态融合功能。

当前 SmartWear V2 数据帧实际对外发送：

| 通道 | 数量 | 当前表示 |
| --- | ---: | --- |
| 加速度 | 3 | `ax, ay, az` |
| 融合姿态 | 4 | 四元数 `qx, qy, qz, qw`（线上顺序） |
| 合计 | 7 | 每颗 IMU 7 个有效数值 |

陀螺仪和磁力计参与 BNO085 内部姿态融合，但当前 137 字节数据帧没有将原始陀螺仪
和原始磁力计读数作为独立通道发送。

## 5. SmartWear V2 数据帧

每件衣服独立发送 137 字节数据帧。帧的主要组成如下：

| 数据块 | 内容 |
| --- | --- |
| 帧头 | `FF FE` |
| 长度字段 | 16 位，固定值 137 |
| IMU 记录 | 6 组，每组 20 字节 |
| 时间扩展 | `UT` 标记、版本、同步状态和帧级 UTC 锚点 |
| 校验 | 最后一字节为帧校验和 |

每组 IMU 记录包含：

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `packet_cnt` | 16 位无符号整数 | 该 IMU 的数据包计数 |
| `sample_time_fine` | 32 位无符号整数 | 该 IMU 的精细采样时间 |
| `acc_x/y/z` | 3 x 16 位有符号整数 | 三轴加速度，Q8 编码 |
| `quat_x/y/z/w` | 4 x 16 位有符号整数 | 姿态四元数，Q14 编码 |

裤子同样发送 6 个协议槽位，但当前有效槽位为：

```text
[0, 1, 2, 4, 5]
```

因此全套衣服的有效传感器数量仍为 11，而不是 12。

## 6. 数值编码

| 数据 | 编码 | 协议数值分辨率 |
| --- | --- | ---: |
| 加速度 | Q8 | `1/256 m/s^2` |
| 四元数 | Q14 | `1/16384` |
| 采样时间 | 32 位计数 | 100 us/tick |

以上是传输协议的量化分辨率，不等于 BNO085 的实际测量精度。姿态误差、噪声、
重复性和长期漂移需要独立标定实验或厂商数据才能给出。

## 7. 采样频率说明

现有测试记录出现过两组原始 BLE 通知频率：

- 部分运行环境约 49-50 Hz；
- 新版 V2 固件单设备约 66-67 Hz。

频率会受到衣服固件、双设备并发、蓝牙控制器、距离和现场无线环境影响。因此正式
对外文件目前只能写“工程实测约 50-67 Hz/件”，不能写成厂家保证采样率。

双设备同时使用时，应分别记录上衣和裤子的有效帧率、丢包数和最大连续断帧时间，
不能只记录两件衣服的平均值。
