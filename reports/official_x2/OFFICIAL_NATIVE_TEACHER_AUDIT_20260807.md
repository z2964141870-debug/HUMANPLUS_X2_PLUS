# AimDK X2 v1.0 官方样例 60 秒 Teacher 数据审计（2026-08-07）

## 结论

官方 X2 MuJoCo、ROS 控制契约和随 SDK 发布的 `kuailechongbai.onnx` 已完成一次连续 60 秒同步采集。数据完整、控制命令覆盖完整、机器人未倒，可作为后续 Stage208 **官方域响应对照和仿真 teacher**；但它只是一条舞蹈样例，不是 locomotion Silver 集，也不是实机动力学真值。

## 数据契约

- 来源：AimDK X2 v1.0 官方 MuJoCo + 官方随包 ONNX。
- 标签：`official_simulation_truth_not_real_hardware_truth`。
- 频率与长度：3000 帧，50 Hz，59.98 s。
- 本体状态：31DOF `q/dq/effort`。
- 控制命令：31DOF `q/dq/effort/Kp/Kd`，3000/3000 帧全关节有效。
- 浮动基座：世界系位置、四元数、线速度和角速度。
- 躯干 IMU：姿态、角速度、线加速度。
- SHA256：`72a495c62b448e322281785738454e4dd6636de568b11ca3d023477c33b063d5`。

| 指标 | 结果 |

## Command-to-state 观测

这里的误差是同帧 `q_actual - q_command`，混合了执行器响应、策略动态动作以及采样相位，不能直接解释为纯静态伺服误差。

| 关节组 | RMSE | p95 绝对误差 | 最大绝对误差 |
|---|---:|---:|---:|
| 腿 | 0.208 rad | 0.444 rad | 1.290 rad |
| 腰 | 0.195 rad | 0.438 rad | 1.244 rad |
| 臂/腕 | 0.228 rad | 0.479 rad | 1.321 rad |
| 头（官方样例不主动控制） | 0.029 rad | 0.064 rad | 0.070 rad |

官方命令使用分组 PD，而不是统一弱 PD：腿部 Kp 包含 40/100/120/150，腰部包含约 40.18/200，手臂包含 20/50；对应 Kd 也按关节组变化。这进一步说明后续匹配审计应逐关节使用官方参数。

## 明确限制

1. `joint_effort` 在当前官方 MuJoCo topic 中全程为 0，不能用于力矩辨识。
2. 没有直接足底 wrench、COP 或真实接触力；这些量若从 MuJoCo 内部补录，必须继续标为官方**仿真**真值。
3. 单条官方舞蹈只证明官方链有效，不能证明 Stage208 locomotion 可迁移。
4. 它适合做响应时序、关节幅值、PD 契约和稳定姿态对照；不应替代 X2 locomotion reference 数据。

## 下一步

以该数据冻结官方域控制契约，并做单变量 matched-control 审计：依次匹配官方逐关节 Kp/Kd、armature、joint friction、自碰撞和接触参数。每次都回放同一输入并报告首次失稳时间、root z/tilt、关节响应误差；只有显著改变失败时间的物理项才进入训练域或随机化配置。
