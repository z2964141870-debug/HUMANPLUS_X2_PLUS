# X2 真机遥操详细操作手册 (transfer-v2 板载版)

> 历史材料，已被当前 Sonic `AGENTS.md`、`CURRENT_STATE.md` 和
> `OPERATIONS.md` 覆盖。不得把本文件当作当前真机操作入口。

## 设备与账号
| 项 | 值 |
|---|---|
| 机器人板载 SSH | `agi@<热点IP>`（密码通过线下凭据获取，不得写入仓库） |
| AIMRT 主控 SSH | `run@10.0.1.40`（密码通过线下凭据获取，不得写入仓库） |
| 板载 conda 环境 | teleop |
| 衣服 BLE 地址 | 上 D5:F4:A2:41:93:4B / 下 F3:FB:AD:FC:7D:82 |
| 热点 | 名称与密码通过线下凭据获取，不得写入仓库 |

---

## 第 1 步：开机与手柄站立
1. 给 X2 上电开机，等待系统启动完成（约 1-2 分钟，底部/背部指示灯正常）
2. 打开官方遥控器（PS5 手柄），确保已配对连接
3. **按 L2+X**：机器人进入"预备站立"（腿部慢动作准备）
4. 站稳后按 **R2+X**：进入"力控站立"（完全站起）
5. 预期：机器人站立稳定、可扶住
> 若机器人有异常动作，立即抬机身急停或按 L2+X 回预备

## 第 2 步：网络与热点
1. 手机开热点：名称与密码使用线下保存的设备凭据
2. 等 X2 连上热点（wifi0 自动连接）
3. 在手机热点"已连接设备"里查 X2 的 IP（记为 `<IP>`，形如 192.168.54.x）
> X2 若没自动连，检查热点名密码是否完全一致

## 第 3 步：SSH 进入并停官方遥操（每次开机必做！）
在你笔记本/电脑终端：
```bash
ssh agi@<IP>             # 交互式输入线下凭据
ssh run@10.0.1.40        # 从 agi 跳登录主控，交互式输入线下凭据
aima em stop-app teleop_bridge   # 停官方遥操桥！防全身抽搐转向
exit                     # 退出 run 主控，回到 agi
```
> ⚠️ 不执行这步，X2 自带遥操会抢占控制，机器人可能抽搐/乱动

## 第 4 步：板载跑 v2 程序
仍在 agi 的 SSH 里：
```bash
cd ~/mocap_teleop/x2_pc1_ble_teleop
conda activate teleop
python ~/x2_v2_teleop/x2_v2_teleop.py --stand-seconds 0
```
预期：打印 `[v2] 板载 v2 遥操 | AIMRT ...` 和 `[v2] 连接衣服 BLE...`
> `--stand-seconds 0` = 站立交手柄（你已 R2+X 站立），程序只做遥操
> 若想程序自己站立：去掉 `--stand-seconds 0`（默认发 3 秒站姿）

## 第 5 步：穿衣服与校准
1. 穿戴上衣+裤子动捕服，插好电池（**不插接收器**，X2 蓝牙直连）
2. **摘下手表**等金属/磁性物
3. 等衣服/裤子 BLE 连接成功提示
4. 看到提示后 **按 Enter**
5. **立刻保持 T-Pose**（站直、手臂自然下垂）
6. **保持 3 秒**，等待校准完成
7. 观察程序打印的衣服/裤子频率：**低于 30Hz 就 Ctrl+C 重跑**
> 校准期间不要动，T-Pose 要标准

## 第 6 步：模式选择与遥操
程序控制台按键：
- **[1]** 官方手柄模式：程序停发，机器人由手柄官方控制（走/站）
- **[2]** 衣服 v2 遥操：transfer-v2 策略接管（跟随你动作）
- **[e]** 急停：立即停发（机器人保持/官方接管）
- **[q]** 退出

实测流程建议：
1. 先按 **[1]**（默认手柄模式）确认手柄正常
2. 按 **[2]** 切到衣服遥操 → 小幅动作（摆臂）→ 观察机器人跟随
3. 幅度满意再逐步加大动作
4. 有问题按 **[e]** 或手柄 R2+X 回力控站立

## 手柄键位速查（官方）
| 键 | 功能 |
|---|---|
| L2+X | 预备站立 |
| R2+X | 力控站立（**紧急情况按它回力控站立**） |
| R2+O | 切换遥操 |

## 第 7 步：关机
1. 手柄 **L2+X**（回预备/下蹲准备）
2. 手柄 **L1+R1+创建键**（左边三竖键）—— 解除/停机
3. 再关机器人电源

## 安全要点（必读）
- **每次开关机都要重做第 3 步**（停 teleop_bridge）和 BLE 低延迟设置
- **不能做单膝跪、后仰**动作（前版限制，策略/硬件不保证）
- 全程急停就位：机身红钮 > 手柄 R2+X > 程序 e 键
- 首次/吊挂测试：条件允许先吊挂验证
- 衣服频率 <30Hz：重启程序或检查蓝牙距离
